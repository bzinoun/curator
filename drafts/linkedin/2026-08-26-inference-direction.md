"Users of this app keep asking for a watch version — there's a niche."

No. There usually isn't.

I measured it: 197 documented feature requests across 100 apps. Median: ONE
request per app. That's not demand, that's one person's comment. Ranking
opportunities on it optimizes for other people's user bases, not unmet needs.

The inference that works runs forward: this search term attracts steady demand,
the shelf serving it is weak → the function is underserved. Market-level signal,
not product-level.

Same data, opposite direction, completely different decisions.
